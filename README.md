# URLオートフィル (chrome-autofill-extension)

ページのURLごとにフォームの入力内容を**自動保存**し、次回アクセス時に**自動で再入力**するChrome拡張(Manifest V3)です。

## 機能

- **自動保存** — input / textarea / select / checkbox / radio の値を、変更・フォーカスアウトのタイミングで自動保存
- **自動再入力** — 同じURLにアクセスすると保存値を自動セット(React等のフレームワークでも動作するようネイティブsetter + イベント発火済み。SPAの遅延描画に備えて1秒後・3秒後にリトライ)
- **URL単位の管理** — `origin + pathname` をキーに保存。フィールドは `name` / `id` 属性で識別
- **ポップアップUI** — 現在ページの保存フィールド数の表示、機能のON/OFF、ページ単位のデータ削除
- **プライバシー** — データは `chrome.storage.local`(ブラウザ内)にのみ保存。外部送信なし

## インストール

1. このリポジトリをクローン(またはZIPダウンロードして展開)
   ```bash
   git clone https://github.com/YumT/chrome-autofill-extension.git
   ```
2. Chromeで `chrome://extensions` を開く
3. 右上の「**デベロッパーモード**」をON
4. 「**パッケージ化されていない拡張機能を読み込む**」→ クローンしたフォルダを選択

## 使い方

1. 任意のフォームページで普通に入力する → 自動で保存されます
2. ページを再読み込み(または再訪問)すると、保存した値が自動で入ります
3. ツールバーの拡張アイコンから:
   - 現在ページの保存フィールド数を確認
   - 自動保存・再入力のON/OFF切り替え
   - 現在ページの保存データを削除

## ファイル構成

| ファイル | 役割 |
|---|---|
| `manifest.json` | MV3マニフェスト(権限: storage / activeTab / tabs) |
| `content.js` | 自動保存・自動再入力の本体(全ページで動作) |
| `popup.html` / `popup.js` | 設定・管理用ポップアップ |

## 注意事項

- パスワード欄の値もローカルに保存されます。共有PCではご注意ください
- クエリパラメータ(`?key=value`以降)はキーに含まないため、同じパスのページでは同じデータが使われます
- `name` / `id` 属性のないフィールドは保存対象外です
